# social/

Assets públicos (cards de carrossel e vídeos verticais) que o Metricool busca por URL raw do GitHub
para publicar nas redes do Viagem ao Passado. Branch órfã social-assets (fora da main, não mexe no app Lovable). Uma pasta por mês.

URL pública: https://raw.githubusercontent.com/trendaisac-rgb/viagemaopassado/social-assets/<mes>/<arquivo>

Todas as fotos e clipes são de domínio público (Wikimedia Commons, Archive.org, NASA, LoC); a fonte de
cada peça está no `manifest.json` da semana.
